# Dashboard

![Abbildung 16](Abbildung16_Dashboard.png)

Nach der Anmeldung siehst du immer erst einmal das Dashboard. Auf dem Dashboard hast du die Übersicht über deine Termine, deinen Notenschnitt, etc. Über „Widgets managen“ (vgl. Abbildung 16) kannst du wählen, welche Widgets du angezeigt haben möchtest und welche nicht.
